# Shiliu Eval Protocol v2

Status: locked for Stage 2R-A.

Leakage policy `v3.5-leakage-policy-v2` is assigned before Development/Held-out split. Case-level random split is forbidden. A group closes over query family, target video, near duplicates, shared/republished content, similar uploader series, terminology/answer template, evidence region, language paraphrase, and positive/negative rewrite. The validator reports every shared key crossing splits.

Stage 2R-B selects 8–12 new cases (target 10) without exposing candidate labels. Coverage must include all four states, single/multi span, multi-aspect, multiple evidence groups, semantic-neighbor negative, missing/title-only authority, ASR, long video, and limited cross-language. Mining target is 2 sufficient, 3 partial, 3 insufficient, 2 unverifiable. Only one formal protocol/schema revision is allowed after pilot.

Pilot outcome is Pass when states (especially partial), groups, structured output, agreement, and adjudication are operational without systemic bias. Revise Once covers missing fields or unstable definitions/thresholds, followed by affected-case rerun. Block and Escalate covers persistently unstable states, severe model bias, inability to submit full transcripts, major source reprocessing, platformization, insufficient Judge-eligible cases, or need to modify Frozen V3. Pilot must pass before 2R-C.

The V3 Retrieval View reads identity/truth/retrieval layers for future recall/rank and failure diagnostics. Eval v2 can diagnose V3 but does not authorize V3 retuning. The V3.5 Fine Evidence View reads query, target, group/span/context and source identity for Stage 3R. The V3.5 Sufficiency View reads query, status, aspects, and reason codes for Stage 4A-R/4B. No V4 Answer or Agentic Search view exists.

Expansion later stops by coverage, saturation, and marginal value—not elapsed time. Stage 2R-A does not judge saturation.
