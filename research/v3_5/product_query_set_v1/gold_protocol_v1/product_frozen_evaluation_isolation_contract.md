V3.5-B must not know relevant or acceptable video IDs, hard-negative video IDs, required aspects, evidence groups, required spans, sufficiency status, reason codes, or expected failure.

The only authorized construction route is:

`Guarded Packet Export → Independent Annotation → Independent Review → User Adjudication if required → Mechanical Validation → Seal`

Future access requires an explicit task contract, purpose limitation, access logging, and no protected content returned to V3.5-B. This P6 freeze creates no packet, opens no Frozen Query content for Gold construction, and creates no Frozen Gold.

After sealing, changes are allowed only for a proven annotation or identity defect, require independent adjudication and a new Gold version, and must never be driven by system results.
