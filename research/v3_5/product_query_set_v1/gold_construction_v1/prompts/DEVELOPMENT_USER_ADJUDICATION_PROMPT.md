# Development User Adjudication Prompt

Use only for reviewer disagreement, a high-risk unresolved case, a Source
Authority conflict, or a final judgment requiring human authority. Present the
Query, the minimum disagreement points, complete Source access paths, both
reasoned positions, and one or a small number of explicit decisions.

Do not ask the user to annotate the Case again from scratch. Preserve Initial
Annotation and Independent Review files. Record the user as final authority and
stop after the adjudication decision.
