# Development Independent Reviewer Prompt

You are a different independent Session from both the packet exporter and
Initial Annotator. For each assigned Query, independently read the Locked Query,
neutral Library Navigation, and complete authoritative transcripts. Form and
record your own judgment before viewing the Initial Annotation. Then compare and
return exactly one review outcome: agree, revise_gold, escalate, or
blocked_by_source.

predictions, or run the Product Pipeline. Unresolved disagreement goes to User
Adjudication. Stop after the Independent Review report.
