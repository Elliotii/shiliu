# 拾流统一稳定基线

基线形成于 2026-10-22，公开快照整理于 2026-10-23。本次在既有 Deep V2/Jev B0/流式展示公开分支上更新产品实现，不包含本地研究分支的私人历史、原始对话或运行数据。

## 更新内容

- 回迁已验收的 Demo 通用修复，包括 Reduce 独立预算及原 S 路径回退、同步与锁相关修补。
- Assistant 使用稳定追加、有界工具交付和完整 Provider 请求预算；达到容量压力时，通过一次 low thinking 摘要提交检查点并接续任务。85% 是预防性触发线，压缩后整请求约 32K 是软目标，TaskNote 没有独立业务长度硬上限；真实 Provider 限额及 Run 预算继续生效。
- 修正正式消息身份、Wiki 来源表达、已保存页面的新编辑及检查点状态显示。正常参数修复采用工具声明中的 replacements，不恢复旧 corrections 调用合同。
- 撤回过度自然语言语义门禁，保留真实身份、来源、版本、范围、事务和有限明确否定保护。入口与对应面板名称统一为 Wiki。
- 保留 Fast F1、Deep B0/S、Memory 时间 v2、Wiki 和同步功能。当前数据库为 Schema 26；包版本仍为 0.3.0。

## 验证及范围

本地对应产品版本已经分批完成 Demo/Context 定向验收、真实 HTTP 保存与同页编辑、一次真实 low 摘要提交/接续，以及独立模拟用户的研究、核查、保存和新对话找回。自然体验中存在一次来源失败，模型自行修复；早先受控体验也存在人工干预，不将它们表述为全部无干预通过。

对应本地候选已从 Git 独立导出，使用全新 Python 3.12 环境及锁定依赖构建 wheel，检查非 editable 包导入、关键页面资源、CLI 和 Schema 26 空库初始化。公开快照另用全新锁定依赖环境核对：278 个产品源码/依赖文件与本地交付完全一致；更正/API 回读、partial 投影、当前 replacements 协议修复三个离线用例通过。新增来源协议样例仅保留合成结构，原有公开合成样例不回填真实原文。不把重复覆盖累加成总通过数。

## 已知限制

- 不要求历史测试全绿。旧 corrections 参数、旧交付前置/后台夹具、分页断言及旧时间字段等仍有适配事项；本轮不全面修复或复跑全部历史用例。
- 模型可能出现边界解释、计数、措辞和语义判断错误；程序不穷尽判断所有自然语言授权。完整 UI、极限容量和所有历史 Thread 的继续执行未全面覆盖。
- 本地估算与实际 usage 有偏差，现有容量参数保留为初值；没有为此新增压缩比例、复杂冷却或多级摘要机制。
- 真实运行需要自己的配置、凭据、语料及可选检索模型。测试不自动同步到日常数据；发布代码不意味着日常实例已切换或正式数据迁移已验收。

## 安装与数据边界

按 README 使用独立虚拟环境，或使用 `uv sync --locked --extra test --python 3.12`。需要本地 Qwen 检索时按已有配置安装可选依赖和准备权重。明确设置独立的 SHILIU_STATE_DIR、SHILIU_CONTENT_DIR 后再体验；只处理前台任务可使用 `shiliu serve --no-background`。

原有公开合成样例继续保留，新增来源协议样例使用合成内容，不附带私人原文、真实 Run 标识、数据库、凭据、模型缓存或本地报告路径。公开快照的 Git 历史沿既有公开分支，不推送本地研究历史或其基线 Tag。
