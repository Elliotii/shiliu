# 拾流 0.4.0 — PostgreSQL 阶段版本

拟用 Tag：`v0.4.0`（本地准备，尚未创建或发布）。

- 正式存储迁移到 PostgreSQL + pgvector；Schema HEAD `0014_assistant_source_patch`。Collection 字幕使用 pg_textsearch BM25，与本地 Qwen Dense/RRF 融合。
- Fast 接入已验证的 Wide-30 原文装填；Deep 保持自身证据链。
- Assistant 增加显式字幕 BM25 Scope、JSON/TXT 精确 Search→Read，以及消息中心的变更、建议、Diff、来源、已读与历史界面。默认综合检索未被替换成字幕专搜。
- Wiki 无人值守正文增补/修订先确认；显式授权保存不重复确认。Memory 沿用既有提炼、更正、遗忘与版本保护，自动新建撤回暂缓。
- 修复 Runtime 重复 Job 收尾/异常隔离、收藏同步已确认的续租锁冲突、Wiki 旧来源表示兼容。
- 固化当前0014配对备份入口，保留停写、精确实例、全表/文件校验及独立空目标恢复保护。

安装要求：Python>=3.10（本次验证3.12）、PG18.6、vector0.8.7、pg_textsearch1.5.1、固定离线Qwen 512维及本地B站CLI。数据库/扩展需管理员准备；不是无前置依赖的一键安装。首次运行建议禁用后台，模型/ASR及自动同步需明确配置和费用授权。

质量结果见[评测摘要](POSTGRES_EVALUATION_SUMMARY.md)。不将有限Gold覆盖等同答案准确率，不宣称零幻觉、长期无故障、公网多用户或跨环境性能提升。Research/Context7不在本次新增正式验收范围；保留旧失败记录不代表全部历史任务自动可恢复。

升级前备份PG和Artifact；无法靠降Wheel回退Schema。新快照以公开main为父提交，不携带私有迁移、部署、评测运行历史或正式资料。当前正式实例未因版本整理重新部署。

验证结果见[候选验证](v0.4.0_VALIDATION.md)。W14历史ETL不是当前0014的通用一键直迁入口，本次只固化当前运行库的配对备份/恢复，不扩大历史导入兼容范围。
