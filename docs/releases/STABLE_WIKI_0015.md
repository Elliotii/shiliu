# 稳定版 Wiki 与知识生命周期更新

本次是 PostgreSQL v0.4.0 之后的稳定产品更新，包版本暂保留 0.4.0，数据库 HEAD 为 `0015_wiki_source_suppression`。发布分支从公开 main 整理最终代码快照，不携带内部开发历史。

## 行为变化

- 显式保存讨论使用持久化异步 Wiki Job，支持新建与原页更新、进度回执和显式重试；更新保留版本、来源及并发检查。
- 普通 Memory 更正或遗忘与独立 Wiki 生命周期分开；明确针对 Wiki 的隐私来源抑制仍生效。
- 删除阻碍正常概括保存的受限上下文、逐句引文匹配和转述分类检查；实际授权、来源身份、可见范围、事务和幂等检查仍保留。
- Wiki 发布只依赖实际引用材料，不因历史探索搜索集合变化而失败；已验证材料正文相同时，历史页可正常读取并记录当前运行依赖，块内原始来源不改写。
- 显式重试复用已返回草稿；结果未知的生成不会被自动重复调用。后台成员查询限定到相关视频。
- 配对备份支持 0014/0015，并限定三个产品 Schema，不要求扩大权限读取同库独立评测数据。

## 发布范围

包含产品源码、迁移、合成测试和备份说明。产品直接引用的轻量观测模块随包保留，默认关闭；仅在操作者显式配置私有输出目录和调用上下文时记录，不包含评测服务、题集、成绩或工作台。

不包含面试版的提示词优化、搜索统计优化、模型预热、专用服务与启动关闭脚本。运行产品源码对应本地稳定版本的最终快照；PR 提交具有独立身份。

不上传数据库、Artifact、原始对话、模型输出、配置正文、凭据、内部报告或评测资料。本次提交不调整正在运行的日常与面试服务，不创建版本 Tag 或 GitHub Release。

## 升级边界

0015 在 `assistant_memory_suppressions` 增加一个可空 JSONB 列，不重写旧记录；没有自动 downgrade。已有实例应先停写，保留 PG + Artifact 配对备份，再升级和安装，详见[备份与恢复](../operations/POSTGRES_PAIRED_BACKUP.md)。运维工具仍要求原有精确资源绑定，不是任意数据库的一键安装器。

文字忠实度由 Writer 提示及质量评估承担；本轮工程检查不代表答案质量、耗时或长期稳定性评测。此前公开聚合成绩不作为本次新增成绩。

## 本轮必要验证

- 干净环境 `uv sync --locked --extra test --no-editable --offline` 成功，依赖锁未变；未安装或启动本地大模型。
- 33 项 Python 定向检查通过：正常概括与授权/来源身份、局部读取覆盖、Writer 请求形态、默认关闭的观测模块、Wiki 保存/幂等/重试、Memory 与 Wiki 解耦，以及 0014/0015 配对备份恢复。数据库场景使用独立随机测试库和 Stub Provider；外部 HTTP 被禁止。
- 历史 Wiki 读取兼容性的 3 个场景通过：仅元数据变化保持可读、实质正文变化过滤对应块、忽略来源过滤对应块；原始来源记录及空间隔离保留。
- 3 项 JavaScript 检查通过：保存状态不会被旧响应覆盖、导航隔离及异步确认回执。
- 最终 Wheel 非 editable 安装后从隔离 Python 导入入口，372 个包文件逐字节核对成功，包含 0015 SQL 与版本脚本。
- 发布的全部产品源码变更与冻结稳定源码逐字节相同；候选新增及修改文件检查未发现个人 home 路径、内部证据目录、真实会话标识或常见真实凭据格式；`git diff --check` 通过。

本轮没有重新执行全量历史测试、大规模质量评测、真实模型调用或长期运行演练。第三方 jieba 转义警告及 pytest 报告格式警告不影响通过项。
