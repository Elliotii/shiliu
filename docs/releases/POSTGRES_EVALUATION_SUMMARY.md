仅发布已独立验收的聚合结果和口径；私有S0语料、Query/Gold、用户收藏、模型原始请求/答案及部署日志不公开。本摘要不声称公开仓库单独附带完整私有评测集，也不重新跑旧版本。

## 固定词法变量（2026-10-26）

同S0、Dev36 + Test50、原Gold/Scorer、固定Dense、分词/过滤/Top-K/RRF及旧Context预算，只替换词法实现。Test50中45道可回答题共82必要点，另5不足题不计正向覆盖分母。

| Test45 macro | PG ts_rank | pg_textsearch BM25 |
|---|---:|---:|
| 原文必要点范围覆盖@10 | 52.22% | 60.74% |
| 原文必要点范围覆盖@50 | 73.33% | 78.15% |
| Context必要点范围覆盖 | 59.26% | 65.93% |

这是Gold证据范围覆盖，不是全库穷尽Recall或答案准确率；仍有逐题退化。固定Dense下原文@10增加8.52个百分点，可归于该受控词法替换。

## Context装填实验（2026-10-27最终独立复核）

同冻结BM25/Dense/RRF候选与S0，A阶段86题离线装填；B阶段三种新策略各完整Test50，另有预固定同批Baseline校准。历史Baseline答案没有重跑完整50题，不能称严格同批单变量答案对照。

| Wide-30 Test45 | 最终结果 |
|---|---:|
| Context原文覆盖 macro | 77.04% |
| 答案必要点完成 macro | 88.15% |
| 完成点总数（micro分母） | 70/82 = 85.37% |
| 严格引用语义支持 | 182/223 = 81.61% |
| 5道不足题职责完成 | 2/5 |
| 整批Test50 Provider usage估算费用 | $0.267011 |

macro是逐题计分后平均，不能把88.15%写成70/82。严格引用支持单独计算，不等同必要点完成或零幻觉。同批Wide-30相对Moderate必要点macro增加7.41个百分点；仍有作者归属、适用条件及干扰材料问题。Wide-50额外费用较高且本批必要点更少，因而选Wide-30落地，不据单次实验宣称普遍显著优势。

实验的TTFT/生成时间是在Context预先准备之后观察，不能冒充完整产品首字延迟或端到端加速。费用是当时Provider usage与费率估算，非未来价格或账单承诺。Test50已多次用于分析；新旧SQLite/PG答案差异还受模型、Prompt、时点及评分修正影响，不能直接归因BM25。
